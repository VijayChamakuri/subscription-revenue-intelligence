# Screenshot Policy

No dashboard screenshots are stored yet. Images must come from the real, refreshed, QA-verified Power BI report. Do not add mockups, generated dashboard images, placeholder PNGs, or fabricated benchmark captures as evidence.

When available, capture all eight report pages at a legible resolution with synthetic-data disclosure, last refresh, and relevant filter state visible. Record the refresh identifier and file hash in the technical report. Use descriptive filenames and alt text.
